PolyLang

Many Domains, Many Paradigms, Many Languages

by Everett Richards

Features

  • Custom Lua-inspired syntax
  • Support for mathematical parsing
  • Nested for loops and if statements
  • Support for embedded code in many general
    purpose and domain-specific languages
  • 10 languages supported

Supported Languages

  • Java
  • JavaMini (headless Java)
  • JavaScript
  • C/C++
  • C#
  • Python
  • Lua
  • R
  • Racket

Examples


# FizzBuzz

for(i:1,100,1)do
    if(i%3==0)then
        if(i%5==0)then
            print("FizzBuzz")
        else
            print("Fizz")
        end
    elseif(i%5==0)then
        print("Buzz")
    else
        print(i)
    end
end

# Embedded C++

poly(c++){polystart}
    #include 
    int main() {
        std::cout << "Hello from C++!" << std::endl;
        return 0;
    }
{polyend}
